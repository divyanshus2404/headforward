leantokens · open source · one Python file

Your agent reads everything what matters.

Coding agents burn most of their tokens re-reading tool output: JSON from APIs, logs, file reads. leantokens sits between the agent and the model and shrinks that output before it is sent. You keep using Claude Code or Codex exactly as before.

How it saves

Same answers, smaller context.

JSON becomes a table

Lists of same-shaped objects repeat every key on every row. leantokens writes the keys once and the values as rows. Nothing is dropped.

Logs lose the noise

Repeated lines collapse to one with a count. Terminal color codes, trailing spaces and runs of blank lines go.

Prompt caching keeps working

The same tool output always compresses to the same bytes, so Anthropic and OpenAI cache hits on earlier turns still land.

Use it your way

Wrap an agent, run a proxy, or pipe a prompt.

Wrap a coding agent

Starts a private proxy, launches the agent pointed at it, and prints what you saved when you quit.

# Claude Code leantokens wrap claude # Codex CLI, API key login leantokens wrap codex # totals so far leantokens stats

Proxy for any app

Point your own code or SDK at the proxy. Keys pass straight through to the provider and are never stored.

leantokens proxy # then, in your app's shell export ANTHROPIC_BASE_URL=http://127.0.0.1:8787 export OPENAI_BASE_URL=http://127.0.0.1:8787/v1

Compress a prompt

For chat apps. Cuts filler, greetings and repeats from what you paste into Claude or ChatGPT.

# clipboard in, clipboard out (macOS) pbpaste | leantokens - -l high | pbcopy # tool output from a file leantokens api.json --tool
Install

One command. No dependencies.

Python 3.9 or newer on macOS, Linux or Windows.

  1. Install from PyPI.

    pip install leantokens

    No pip? Copy the script instead, save it as leantokens.py, and run python3 leantokens.py wherever this page says leantokens.

    # macOS: save what you just copied pbpaste > leantokens.py

    Linux: xclip -o -sel clip > leantokens.py. Windows: paste into Notepad and save as leantokens.py.

  2. Run your agent through it.

    leantokens wrap claude

  3. Optional: exact token counts.

    pip install "leantokens[exact]"

Know before you run it

What it does not do.

  • It only touches tool output. Your messages and the system prompt reach the model unchanged.
  • Savings depend on the work. JSON-heavy and log-heavy sessions save the most. Sessions that mostly read source code save little, because code is left as written.
  • Codex with a ChatGPT login talks to ChatGPT's servers, not the API, so it bypasses the proxy. Use an API key login.
  • Chat apps in the browser (claude.ai, chatgpt.com) can't be proxied. Use the prompt compressor and paste.
