leantokens · open source · one Python file

Your agent reads everything what matters.

Coding agents spend most of their tokens re-reading tool output: build logs, test runs, JSON, file reads. leantokens shrinks that output before the model sees it. You keep using Claude Code exactly as before.

Three ways in

Pick the route that fits how you run Claude.

Hooks work everywhere Claude Code runs. The proxy routes also compress JSON and repeated reads, but only for agents that honor a base URL.

Hooks

Filter noisy commands

A Claude Code hook pipes test, install and build output through the filter. Runs inside every session, including the desktop app.

leantokens hooks install global
Always-on proxy

Compress every request

A background proxy that starts at login. Terminal Claude Code uses it in every project. Undo restores your settings.

leantokens desktop on global
Wrap

One session at a time

Starts a private proxy, launches the agent pointed at it, and prints what you saved when you quit.

leantokens wrap claude

New · gateway chaining

Already using a gateway? leantokens goes in front of it.

If your Claude Code settings already point ANTHROPIC_BASE_URL at a router, cost tracker or company proxy, desktop on no longer refuses. It takes that URL as its upstream, so nothing you rely on is skipped.

Claude Codeyour session
leantokens127.0.0.1:8787shrinks tool output
Your gatewaye.g. 127.0.0.1:17322routing, logging, keys
Anthropicapi.anthropic.comthe model

Turn it on

# detects the existing URL and forwards to it leantokens desktop on global # Chain: Claude Code -> leantokens -> http://127.0.0.1:17322 leantokens desktop status

Turn it off

# stops the proxy and puts your gateway URL back leantokens desktop off

An ANTHROPIC_BASE_URL exported in your shell beats Claude Code settings, so it skips the chain. leantokens doctor tells you when that happens.

How it saves

Same answers, smaller context.

Logs lose the noise

Repeated lines collapse to one with a count. Progress bars, color codes and runs of blank lines go. Error lines are always kept.

PASS test_a … PASS test_z → PASS [x26]

JSON becomes a table

Lists of same-shaped objects repeat every key on every row. leantokens writes the keys once and the values as rows. It rebuilds to the exact original.

{"id":1,"status":"paid"},{"id":2,… → id|status

Repeats become pointers

Agents re-read the same file and rerun the same tests. A tool result identical to an earlier one becomes a one-line pointer to it.

Prompt caching keeps working

The same output always compresses to the same bytes and earlier turns never change, so cache hits still land.

Install

One command. No dependencies.

Python 3.9 or newer on macOS, Linux or Windows. The always-on proxy needs macOS.

  1. Install from PyPI.

    pip install leantokens

    No pip? Copy the script, save it as leantokens.py, and run python3 leantokens.py wherever this page says leantokens.

  2. Check your setup. It says exactly what to fix.

    leantokens doctor

  3. Turn on the route you want, then start a new Claude Code session.

    leantokens hooks install global

  4. See what you saved.

    leantokens stats

Know before you run it

What it does not do.

  • It only touches tool output. Your messages and the system prompt reach the model unchanged.
  • It never stores your keys. Sign-in and API keys pass straight through to the provider. Everything runs on your machine.
  • History is the bigger cost. Every reply resends the whole conversation. /clear between tasks and /compact in long sessions save more than any filter.
  • Savings depend on the work. Log-heavy and JSON-heavy sessions save the most. Reading source code saves little, because code is left as written.
  • The desktop app skips the proxy. Its Code sessions ignore ANTHROPIC_BASE_URL. Use hooks there.
  • A shell variable wins. ANTHROPIC_BASE_URL exported in your shell overrides Claude Code settings, including the always-on proxy.
  • Codex with a ChatGPT login talks to ChatGPT's servers, not the API, so it bypasses the proxy. Use an API key login.
  • Chat in the browser (claude.ai, chatgpt.com) can't be proxied. Compress a prompt here and paste it.
