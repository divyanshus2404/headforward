Your agent reads everything what matters.

Coding agents spend most of their tokens re-reading tool output: test runs, build logs, git output, JSON. headforward shrinks that output before the model sees it. Errors are always kept, and you keep using Claude Code exactly as before.

How it saves

Smaller context. Nothing dropped.

JSON becomes a table

Lists of same-shaped objects repeat every key on every row. headforward writes the keys once, the values as rows, and any value shared by every row just once. It rebuilds to the exact original.

Repeats become pointers

Agents re-read the same file and rerun the same tests. A tool result identical to an earlier one becomes a one-line pointer to it.

Logs lose the noise

Repeated lines collapse to one with a count. Terminal color codes, trailing spaces and runs of blank lines go.

Prompt caching keeps working

The same tool output always compresses to the same bytes and earlier turns never change, so Anthropic and OpenAI cache hits still land.

Measured

How much it saves depends on what your agent reads.

Data and logs shrink a lot. Source code is left exactly as written, so code-heavy sessions save less. Counted with OpenAI's o200k tokenizer.

Three ways in

Pick the route that fits how you run Claude.

Hooks work everywhere Claude Code runs. The proxy routes also compress JSON and repeated reads, in the terminal and, with --https, the desktop app.

Hooks

Filter noisy commands

Tests, installs, builds, git log, ls -l and grep pass through the filter. Runs in every session, desktop app included.

headforward hooks install global
Always-on proxy

Compress every request

Starts at login (macOS) and serves Claude Code in every project. Add --https to reach the desktop app too. Off restores your settings.

headforward desktop on global
Wrap

One session at a time

Starts a private proxy, launches the agent pointed at it, and prints what you saved when you quit.

headforward wrap claude

Gateway chaining

Already using a gateway? headforward goes in front of it.

If your Claude Code settings already point ANTHROPIC_BASE_URL at a router, cost tracker or company proxy, desktop on takes that URL as its upstream, so nothing you rely on is skipped.

Claude Codeyour session
headforward127.0.0.1:8787shrinks tool output
Your gatewaye.g. 127.0.0.1:17322routing, logging, keys
Anthropicapi.anthropic.comthe model

Turn it on

# detects the existing URL and forwards to it headforward desktop on global headforward desktop status

Turn it off

# stops the proxy and puts your URL back headforward desktop off

An ANTHROPIC_BASE_URL exported in your shell beats Claude Code settings and skips the chain. headforward doctor tells you when that happens.

Install

One command. No dependencies.

Python 3.9 or newer on macOS, Linux or Windows.

  1. Install from PyPI.

    pip install headforward

    No pip? Copy the script instead, save it as headforward.py, and run python3 headforward.py wherever this page says headforward.

    # macOS: save what you just copied pbpaste > headforward.py

    Linux: xclip -o -sel clip > headforward.py. Windows: paste into Notepad and save as headforward.py.

  2. Turn on the hook, then start a new Claude Code session.

    headforward hooks install global

  3. Check your setup. It says exactly what to fix.

    headforward doctor

  4. Optional: exact token counts.

    pip install "headforward[exact]"

Questions

Before you try it.

Does it change the model's answers?

The default rules are lossless: every compressed result can be rebuilt exactly, or points to an identical copy already in the conversation. Whether a model behaves the same on your work is something you can check: headforward eval replays your recorded requests with and without compression and compares the answers.

Is my API key or Claude sign-in safe?

The proxy runs only on your computer, listens on 127.0.0.1, and passes credentials straight to Anthropic or OpenAI. They are never stored or logged. In --https mode it decrypts only api.anthropic.com, with a local certificate that can vouch for nothing else; every other site gets a plain tunnel it never reads.

Does it break prompt caching?

No. Compression is deterministic and never rewrites earlier turns, so each request still begins with the same bytes as the last one and cache hits keep landing.

Does it work with claude.ai or chatgpt.com?

Those sites talk directly to their own servers, so no proxy can sit in between. You can compress text before pasting it: pbpaste | headforward - -l high | pbcopy on macOS.

How do I know it's working?

In a new Claude Code session, run something noisy like your tests. Shortened output carries a line such as [40 passing test lines omitted; full output: headforward show ID]. headforward stats counts every request it touched.

What if something goes wrong?

Undo it in one command: headforward hooks uninstall global or headforward desktop off. Both restore your Claude Code settings from a backup, and plain claude works exactly as before.

What does it cost?

Nothing. It's MIT-licensed, one Python file, no account and no telemetry.

Know before you run it

What it does not do.

  • It only touches tool output. Your messages and the system prompt reach the model unchanged.
  • Savings depend on the work. JSON-heavy and log-heavy sessions save the most. Sessions that mostly read source code save little, because code is left as written.
  • History often costs more. Every reply resends the conversation. /clear between tasks and /compact in long sessions save more than any filter.
  • The desktop app needs --https. Its Code sessions ignore ANTHROPIC_BASE_URL, so desktop on --https serves them as their HTTPS proxy instead. If that proxy is down, those sessions can't connect until you run headforward desktop off.
  • A shell variable wins. ANTHROPIC_BASE_URL exported in your shell overrides Claude Code settings, including the always-on proxy.
  • Codex with a ChatGPT login talks to ChatGPT's servers, not the API, so it bypasses the proxy. Use an API key login.
  • Chat apps in the browser (claude.ai, chatgpt.com) can't be proxied. Use the prompt compressor and paste.
